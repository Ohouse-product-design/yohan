# 인테리어/생활 탭 개편 프로토타입

오늘의집 앱 `인테리어/생활` 탭을 **"시공 리드 퍼널"에서 "이사·집 준비 홈"으로** 재정의한 개편안.
`index.html`을 브라우저로 열면 됩니다. (React + Babel standalone, 빌드 불필요 — `apartment-ex`와 동일한 방식)

## 풀려는 문제

1. 계약 의사가 없는 이사 계획 유저가 이 탭을 **자주 방문**하게 만들 것
2. 원하는 메뉴를 **빠르게 찾게** 만들 것

## 현재안 진단

스크린샷 기준 모듈 12개 중 11개가 시공 리드. `생활`은 칩 3개가 전부다.

- **중복 진입점** — 견적계산기 4곳, 업체찾기 3곳, 직영시공 3곳. 모듈은 12개지만 실제 목적지는 6~7개.
- **탭 전체 지도(`전체서비스`)가 4번째 스크롤**에 아이콘 하나로 묻혀 있음.
- **유저 상태와 무관하게 항상 같은 순서** — D-60인 사람과 견적 3곳 받은 사람이 같은 12단 스크롤을 봄.
- **재방문 자산인 견적 순위 데이터가 최하단** — 계약 없이 반복 소비 가능한 유일한 데이터인데 가장 안 보이는 곳에 있음.

## 개편안 구조 — 3층

| 층 | 내용 | 푸는 문제 |
|---|---|---|
| **L1** 내 상태 + 전체 지도 | 이사 D-day 카드 + 진행률, 서비스 그리드 8칸 | 빠른 탐색 (스크롤 0에 전체 지도) |
| **L2** 지금 할 일 | D-day 구간별 체크리스트 3개 | 재방문 (미완료가 남아 있으면 돌아옴) |
| **L3** 우리집 예상 견적 | 우리 단지 평균가 + 6개월 추이 + 알림 | 재방문 (계약 없이 매달 볼 이유) |
| **L4** 우리 동네 소식 | 반경 4km 새 리뷰·사례 + NEW 배지 | 재방문 (항상 새로운 것) |

부수적으로 커머스 검색어(`집요한세일 ~91%`)를 탭 맥락 검색으로 교체.

## 프로토타입 조작

- **현재안 / 개편안 / 나란히** — 상단 세그먼트
- **시나리오 `D-45` `D-20` `D-5` `입주 후`** — 같은 탭이 유저 시점에 따라 다른 얼굴을 갖는다는 축. L2 체크리스트와 진행률이 통째로 바뀜
- **주석 보기** — 현재안의 문제 지점(빨강)과 개편안의 대응(초록)을 화면 위에 표시
- 체크리스트 항목을 누르면 진행률 바가 실제로 움직임
- 견적 추이 그래프는 각 점에 hover하면 해당 월 값 표시

## 파일

```
index.html          진입점
app.jsx             루트 + 상단 컨트롤 바 + 디바이스 스케일링
data.js             더미 데이터 (현재안 재현 + 개편안 시나리오)
icons.jsx           아웃라인 아이콘 세트
ios-frame.jsx       iOS 디바이스 프레임 (apartment-ex 공용)
screens/shell.jsx   앱바 / 바텀네비 / 타일 / 주석 래퍼
screens/current.jsx 현재안 재현 (모듈 12개)
screens/redesign.jsx 개편안 (4개 레이어 + 견적 추이 스파크라인)
```

데이터는 전부 더미입니다. 견적가·리뷰 수·평균가 추이는 구조를 보여주기 위한 예시 값이지 실제 수치가 아닙니다.
